# 报销系统操作指南

## 一、系统入口

登录企业办公平台后，在"财务"模块下进入"费用报销"。首次使用请先在"个人设置"中完善收款银行账户信息，确保报销款项准确到账。

## 二、发起报销

1. 点击"新建报销单"。
2. 选择报销类型：差旅费、采购费、招待费、日常费用等。
3. 关联对应的事前审批单（如出差申请、采购申请）。
4. 逐项填写费用明细：费用科目、金额、发生日期、备注。

## 三、上传票据

- 支持上传 PDF、图片格式的发票。
- 电子发票建议上传原始 PDF，系统可自动识别号码并查重。
- 每笔费用需与对应票据一一对应，金额需一致。

## 四、提交与审批

1. 核对无误后点击"提交"。
2. 报销单进入审批流：直属主管 → 财务复核 → 出纳付款。
3. 可在"我的报销"中实时查看审批进度与节点意见。

## 五、审批状态说明

| 状态 | 含义 |
| --- | --- |
| 待审批 | 等待当前节点处理 |
| 已退回 | 材料不合规，需修改后重新提交 |
| 审批通过 | 进入付款环节 |
| 已付款 | 款项已发放 |

## 六、常见问题

问：报销单被退回怎么办？
答：查看退回意见，按提示补充或更正材料后重新提交，无需新建单据。

问：发票上传后提示重复怎么办？
答：说明该发票已被报销过，请核对是否误传；如有异议联系财务核实。

问：多久能到账？
答：审批通过后一般在下一个财务付款周期内到账，具体以财务排款为准。

## 七、温馨提示

- 请及时报销，避免票据超期。
- 明细务必真实准确，杜绝虚报与重复报销。
- 大额或特殊费用建议提前与财务沟通，避免反复退回。
