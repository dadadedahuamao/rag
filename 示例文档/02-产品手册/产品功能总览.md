# 企业级 RAG 知识库系统 · 产品功能总览

## 一、产品简介

企业级 RAG 知识库系统是一款面向企业内部知识沉淀与智能问答的一体化平台。系统基于检索增强生成（Retrieval-Augmented Generation）技术，将企业文档转化为可被大模型精准调用的知识资产，让员工用自然语言即可获得有出处、可追溯的答案。

## 二、核心能力

### 2.1 多格式文档接入

支持 PDF、Word、Markdown、TXT、HTML 等主流格式的上传与解析。系统自动完成文本抽取、智能切分（分块 + 重叠）与向量化，构建可检索的知识索引。

### 2.2 知识库管理

- 支持创建多个知识库，按部门、主题或项目隔离
- 三级可见性：公开（public）、部门（department）、私有（private）
- 成员授权：为私有库指定只读或可写成员
- 文档全生命周期管理：上传、解析、重建索引、下线、删除

### 2.3 智能问答

- 自然语言提问，自动召回相关知识片段
- 大模型生成答案并标注引用来源（文档名 + 页码）
- 支持流式输出，边生成边展示
- 支持自动选库：根据问题语义匹配最相关的知识库

### 2.4 会话管理

- 多轮对话上下文保持
- 会话历史按用户隔离，支持检索与回看
- 引用溯源，一键跳转到原文片段

## 三、管理与运营

- 仪表盘：知识库数量、文档量、问答量、评测概览等关键指标一览
- 任务中心：文档解析、索引重建等异步任务的进度与状态跟踪
- 评测中心：基于 RAGAS 指标（忠实度、答案相关性、上下文精确率/召回率）的质量评估
- 审计日志：关键操作留痕，满足合规审计要求
- 系统配置：缓存策略与限流参数管理

## 四、权限体系

系统内置三种角色：

| 角色 | 主要权限 |
| --- | --- |
| 系统管理员 | 全量权限，管理所有知识库、用户与系统配置 |
| 知识库管理员 | 管理被授权知识库及其文档 |
| 普通用户 | 问答与只读权限 |

## 五、技术特性

- 检索引擎：Elasticsearch 向量检索 + 关键词混合召回
- 缓存加速：Redis 缓存高频问答，降低重复调用成本
- 大模型：兼容 OpenAI 协议，默认对接 DeepSeek
- 前后端分离：React + FastAPI，部署灵活
